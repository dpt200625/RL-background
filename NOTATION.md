# Notation used throughout

**Time and reward.** At step $t$, the agent observes $S_t$ (or $O_t$), chooses $A_t$, then receives $R_{t+1}$ and $S_{t+1}$. This is the same convention as Silver and Sutton–Barto. In Berkeley, $r(s_t, a_t)$ is usually indexed by the action; when switching to the notation here, it corresponds to the reward generated by the transition $(S_t, A_t)$, i.e. $R_{t+1}$. Do not shift the reward by one more step when computing the return.

| Symbol | Meaning and scope |
|---|---|
| $\mathcal S, \mathcal A$ | State and action sets. Finite sums are used for finite MDPs; the continuous case needs the corresponding integrals/densities. |
| $S_t, A_t, R_{t+1}$ | Random variables; $s, a, r$ are concrete values. $O_t$ is an observation; $H_t$ is the history of observations, actions and rewards. |
| $\mathcal P^a_{ss'}$ | $\Pr(S_{t+1} = s' \mid S_t = s, A_t = a)$, exactly Silver's model notation. |
| $\mathcal R^a_s$ | $\mathbb E[R_{t+1} \mid S_t = s, A_t = a]$, the expected immediate reward, not the return. |
| $\gamma, G_t, T$ | Discount $0 \le \gamma \le 1$; return from $t$; $T$ is the terminal time of the episode. |
| $\pi(a \mid s), \pi_\theta(a \mid s)$ | Policy and parameterized policy. The behavior policy is written $\mu$ as in Silver; Sutton–Barto uses $b$ for the same role. |
| $v_\pi(s), q_\pi(s,a)$ | True values of policy $\pi$. $v_*, q_*$ are the optimal values. These are lowercase, different from the estimates below. |
| $V(s), Q(s,a)$ | Estimate tables being learned, as in Silver. The index $k$ indexes DP update rounds; the index $t$ indexes interaction time. |
| $\hat v(s,w), \hat q(s,a,w)$ | Value approximation with critic parameters $w$, as in Sutton–Barto. $w^-$ is the parameter of the frozen target network. |
| $\alpha, \delta_t, \lambda$ | Step size; TD error; trace/GAE coefficient. $\lambda$ here is the standard algorithm notation, not a proposed objective. |
| $\mathcal D, y, \hat A_t$ | Dataset/replay buffer; learning target; estimated advantage. $A_t$ without a hat is always the *action*. |
| $J(\theta), L(w)$ | Performance objective and learning loss. The name $L$ may be used for the surrogate actor when the parameter is $\theta$, as stated at that place. |

**Symbols used only in the extensions.** $\rho_t$ is the importance ratio; $\eta$ is the parameter of learned dynamics; $z_t$ is a latent state; $g$ is a goal. These are the standard notations of the corresponding parts, defined when they appear. For optimization, $x, f_i, \nu$ keep Boyd's notation; the multiplier $\lambda_i$ has an index to distinguish it from the trace $\lambda$. Berkeley usually uses $\phi$ for the critic; here it is unified as $w$. Renaming variables does not change the mathematical meaning of the formulas.

**Default objective.** Unless a section says otherwise, the notes consider the expected discounted return, an initial-state distribution that is fixed and independent of $\theta$, and reward/dynamics that do not depend directly on the policy parameters. Finite episodes use $v(S_T) = 0$; continuing tasks default to $\gamma < 1$ and bounded rewards. The average-reward problems in Sutton–Barto Ch. 10, 13 are distinguished in general terms and are not mixed into the discounted formulas.

## In the code

| Notes | Code |
|---|---|
| $\mathcal P^a_{ss'}$, $\mathcal R^a_s$ | `mdp.P[s, a, s']`, `mdp.R[s, a]` (`rlcore.TabularMDP`) |
| $R_{t+1}$ of the transition $(S_t, A_t)$ | `traj.rewards[t]` (`rlcore.Trajectory`) |
| terminal vs time limit | `Step.terminated` vs `Step.truncated` |
| $\pi(a \mid s)$, behavior $\mu$ | `policy.probs(s)`, `policy.sample(s, rng)` (`rlcore.policies`) |
| $V(s)$, $Q(s,a)$ | `learner.V[s]`, `agent.Q[s, a]` |
